PaySettle

Agree what done means. Get paid when it is.

Milestone contracts with the money held in PayPal: each capture is tied to the evidence its clause names, and a dispute freezes one milestone, not the project. Built for the PayPal AI Hackathon 2026. PayPal Sandbox only: no real money moves.
